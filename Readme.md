# MealMatez

## Project Name 

MealMatez

## Project Statement

MealMatez is a meal-planning application designed to make weekly food preparation easier and more organized. The goal of the project is to give users one convenient place to plan meals, save recipes, and prepare grocery lists. Instead of deciding what to cook at the last minute, users will be able to organize breakfast, lunch, and dinner for the entire week.

The completed application will allow each user to create a personal account and manage meal plans that fit their schedule and preferences. MealMate will also turn planned recipes into a combined grocery list, helping users save time and avoid forgetting ingredients. The application will connect to a database so that user profiles, recipes, meal plans, and grocery lists can be stored and updated.

## Target Audience

The primary users are busy adults, families, fitness enthusiast and anyone who wants a simple way to organize meals and grocery shopping.

## Core Features

- Users can create an account, log in, and manage a personal profile.
- Users can create, edit, and delete weekly meal plans.
- Users can add, save, update, and search for recipes.
- Users can automatically create a grocery list from their selected meals.
- Users can mark grocery items as purchased and track their shopping progress.
